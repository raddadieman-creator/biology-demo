# BioLab | بيولاب — منصة الأحياء التفاعلية للسنة الأولى المشتركة

منصة للطالبات فيها دروس مبسطة برسوم ونماذج ثلاثية الأبعاد وأنشطة، واختبارات ذاتية بتغذية راجعة فورية، ومسابقة مباشرة داخل الحصة، ومساعدة اسمها «رهف» تجيب بإجابات معدّة توجّه الطالبة بدل إعطائها الحل. وللمعلمة لوحة تحكم لمتابعة الطالبات والنتائج وتحديد المفاهيم التي تحتاج تعزيزًا.

كل الخدمات المستخدمة مجانية: GitHub للكود والنشر، وSupabase لقاعدة البيانات.

---

## ما الذي تحتويه المنصة

**للطالبة** (تدخل باسمها وفصلها دون كلمة مرور)
- الفصل الثامن «المفصليات» من كتاب أحياء 1 (السنة الأولى المشتركة، الفصل الدراسي الأول، طبعة 1448هـ) بثلاثة دروس: خصائص المفصليات / تنوع المفصليات / الحشرات وأشباهها.
- نموذج ثلاثي الأبعاد تفاعلي لكل درس (الجرادة، العنكبوت، التحول الكامل) تضغط الطالبة على أجزائه فتظهر معلوماته.
- لكل جزئية رابط شرح على يوتيوب يفتح خارج المنصة، ولكل درس رسم توضيحي ونشاط تصنيف ومصطلحات بصيغة الكتاب.
- أربعة اختبارات (٣٤ سؤالًا) بخمسة أنواع: اختيار من متعدد، وصواب وخطأ، وإكمال، وترتيب، ومزاوجة، مع تبرير لكل خيار.
- التحديات بكود من المعلمة، ولوحة المتميزات، والألقاب، والشهادة (طباعة وPDF).
- سؤال وجواب: بنك مذاكرة، وملفات المذاكرة، وأسئلة الطالبات للمعلمة، وتنبيهات بكل جديد.
- المساعدة «رهف»: بنك من ٤٥ إجابة معدّة تغطي الفصل. إذا لم تجد إجابة يصل السؤال إلى المعلمة.

**للمعلمة** (رابط «دخول المعلمة» أسفل الصفحة)
- متابعة كل طالبة، والنتائج وإتقان المفاهيم مع تصدير Excel.
- تعديل الدروس والأسئلة ونصوص أجزاء النماذج، ورفع الأسئلة من Excel، وإضافة صورة لكل سؤال.
- رفع ملفات المذاكرة، والرد على أسئلة الطالبات ونشرها، وإرسال تنبيه لكل الطالبات.

> المحتوى النموذجي كُتب على مفاهيم الفصل الثامن ومفرداته من كتاب أحياء 1، وليس نقلًا حرفيًا منه، ويحتاج مراجعة المعلمة قبل الاستخدام. روابط يوتيوب اختيرت بعناوينها، فتحسن مشاهدتها قبل نشرها للطالبات، ويُعدَّل أي رابط من اللوحة.

## خطوات النشر على حساب المعلمة

### ١) GitHub — حفظ الكود
1. أنشئي حسابًا للمعلمة على github.com.
2. من علامة **+** اختاري **New repository**، وسمّيه مثلًا `ahyaei`، واجعليه **Private** أو **Public**.
3. اختاري **uploading an existing file** واسحبي كل محتويات هذا المجلد **ما عدا** مجلد `node_modules` إن وُجد، ثم **Commit changes**.

### ٢) Supabase — قاعدة البيانات
1. أنشئي حسابًا على supabase.com ثم **New project**. احفظي كلمة مرور قاعدة البيانات في مكان آمن.
2. من القائمة الجانبية افتحي **SQL Editor** ← **New query**، والصقي محتوى الملف `supabase/schema.sql` كاملًا، ثم **Run**. (عند أي تحديث للمنصة أعيدي تشغيله؛ الملف آمن للتشغيل أكثر من مرة، ويضيف جداول «سؤال وجواب» وبنك المذاكرة.)
3. افتحي **Authentication** ← **Users** ← **Add user** ← **Create new user**: بريد المعلمة وكلمة مرورها، مع تفعيل **Auto Confirm User**.
4. **مهم للأمان:** في إعدادات **Authentication** أوقفي خيار السماح بتسجيل مستخدمين جدد (Allow new users to sign up)، حتى لا يستطيع أحد غير المعلمة إنشاء حساب يدخل به إلى اللوحة.
5. من **Project Settings** ← **API** (أو **API Keys**) انسخي:
   - **Project URL**
   - المفتاح العام **anon / publishable** (لا تنسخي مفتاح service_role أو secret أبدًا).

### ٣) Vercel — نشر الموقع
1. ادخلي vercel.com بحساب GitHub الخاص بالمعلمة.
2. **Add New** ← **Project** ← اختاري مستودع `mukhtabari` ← **Import**.
3. افتحي **Environment Variables** وأضيفي:
   - `VITE_SUPABASE_URL` = الرابط الذي نسختِه
   - `VITE_SUPABASE_ANON_KEY` = المفتاح العام
4. **Deploy**. بعد دقيقة يظهر رابط الموقع.

### ٤) المساعد الذكي (اختياري، مدفوع بالاستخدام)
1. أنشئي حسابًا على console.anthropic.com وأضيفي رصيدًا، ثم أنشئي مفتاح API.
2. في Supabase: **Edge Functions** ← **Deploy a new function** ← **Via Editor**، وسمّيها `ask`، والصقي محتوى الملف `supabase/functions/ask/index.ts`، ثم **Deploy**.
3. من إعدادات الدالة أوقفي **Verify JWT** (أو Enforce JWT verification).
4. من **Edge Functions** ← **Secrets** أضيفي سرًّا باسم `ANTHROPIC_API_KEY` وقيمته المفتاح.
5. في Vercel أضيفي متغيرًا ثالثًا: `VITE_AI_ENABLED` = `1`، ثم أعيدي النشر.

بدون هذه الخطوة تعمل «رهف» ببنك الإجابات المعدّة. ومع تفعيلها تجيب بالذكاء الاصطناعي مستندة إلى نصوص الدروس في قاعدة البيانات، ويظهر للطالبات أنها مساعدة آلية.

### ٥) أول دخول
افتحي الموقع ← **دخول المعلمة** ← البريد وكلمة المرور ← اضغطي **رفع المحتوى النموذجي**. بعدها تظهر الدروس والاختبارات للطالبات.

## ملاحظات تشغيلية
- **الخمول:** مشروع Supabase المجاني يتوقف إذا لم يُستخدم أسبوعًا. يظهر في المنصة تنبيه واضح، ويُعاد تشغيله من لوحة Supabase بزر **Restore / Resume project**.
- **الفيديوهات:** أضيفيها روابط يوتيوب، فمساحة الملفات المجانية محدودة.
- **المساعدة الذكية:** «رهف» تعمل ببنك إجابات معدّة ولا تحتاج اشتراكًا. ربطها بذكاء اصطناعي يجيب عن أي سؤال يحتاج خدمة مدفوعة تسمح شروطها بالاستخدام مع طالبات دون 18 سنة.
- **متابعة الطالبات:** تُعرَّف الطالبة باسمها وفصلها كما كتبتهما، فإذا كتبت اسمها بطريقتين ظهرت مرتين. اطلبي من الطالبات كتابة الاسم الثنائي نفسه في كل مرة.
- **طبيعة الاختبارات:** الإجابات تُصحَّح على جهاز الطالبة لتظهر التغذية الراجعة فورًا، لذلك المنصة مناسبة للتدريب والتقويم التكويني، لا للاختبارات الرسمية.
- **الاسم والفصول:** تُعدَّل من الملف `src/config.js` (اسم المنصة، اسم المساعدة، قائمة الفصول).
- **تغيير أي شيء في الكود:** عدّلي الملف على GitHub، وسيعيد Vercel النشر تلقائيًا على الرابط نفسه.

## التشغيل على الجهاز (اختياري)
```
npm install
npm run dev
```
دون ملف `.env.local` تعمل المنصة نسخةً تجريبية تحفظ البيانات في المتصفح، وكلمة مرور المعلمة فيها `1234`.
